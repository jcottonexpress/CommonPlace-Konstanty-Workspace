# CommonPlace Candidate Test Workspace

This private repository is an isolated evaluation workspace containing the CommonPlace web storefront and a development API snapshot. It is intentionally separate from the production repository and has no production credentials, customer data, deployment access, mobile application, attachments, exports, or original Git history.

## Candidate workflow

1. Create a feature branch for your work.
2. Keep all development inside this repository and its assigned Replit project.
3. Never add credentials, personal data, or production configuration.
4. Open a pull request in this repository when the work is ready for review.
5. Do not attempt to access or modify the upstream production repository.

## Local configuration

Add development values through Replit Secrets. Never commit a real `.env` file.
